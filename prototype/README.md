# Typetodo 原型 v0.2（在 Typefree 原界面里加待办）

> v0.1 是误做的独立待办 App 界面，已归档到 `_archive/`。**v0.2 才是对的**：沿用 Typefree 的窗口、侧栏、配色与卡片体系，只把待办作为一个新页面接进去。

## 打开

```bash
open prototype/typetodo-prototype-v0.2.html
```

## 对齐了原版的哪些东西

从 `mac/Sources/SettingsWindowController.swift` 与 `AppAppearance.swift` 里抠出来的真实规格：

| 项 | 原版值 | 说明 |
|---|---|---|
| 窗口 | 1100×720，最小 1040×600 | 透明全尺寸标题栏，红绿灯压在侧栏上 |
| 侧栏 | 178px，行高 30，圆角 7 | 分组：工作台 / 配置 / 关于 |
| 内容区 | 左右 56、上 36、下 48，最大宽 880 | 卡片间距 20 |

## 原版有 8 个页面，这一版怎么处理

| 原版页面 | Typetodo 一期 | 理由 |
|---|---|---|
| 首页 | 保留，**加「今日待办」卡片** | 待办要在第一屏被发现 |
| 历史记录 | 保留 | 听写历史 |
| 反馈 | **去掉** | 依赖作者的服务端，一期没有 |
| 个人词库 | 保留 | 听写准确率靠它 |
| 模型 | 保留，**删掉试用/会员** | 一期只做自带 Key |
| 探索 | 保留，**把手势说明改成三条**（说话 / 问 AI / 记待办） | |
| 设置 | 保留，**加「记待办手势」「通知」两项** | |
| 关于 | 保留，改写许可证与来源 | GPL-3.0，基于 Typefree |
| — | **新增「待办」页** | 唯一的新页面 |

侧栏底部原来的「试用/会员」卡片已删除，换成一行状态（自带 Key · 火山识别）。

## 待办页怎么设计的

- 页头右侧「＋ 新建待办」（黑底主按钮，与原版主按钮一致）
- 分段控件切换：**今天 / 收件箱 / 即将 / 已完成**（复用原版 `VPSegmentedControl` 的灰轨道 + 白药丸样式）
- **清单在侧栏第三组**：工作 / 生活 / 新建清单；点某个清单，页面标题变成清单名，分段控件变成"该清单内的时间过滤"
- 列表在卡片内，逾期单独分组置顶标红
- 点一行展开：原始语音 + 标记完成 / 删除
- 不做右侧详情栏——原版没有这种布局，加了就不像它了

> 清单入口是 PRD v1.0 定稿后才补的（见 `docs/05` O-01），原型已同步。
