## 七、实际踩到并已解决的坑（P0 实测）

这一节都是「照着做就能过」，不是理论分析。新机器复现时按顺序看。

### 1. 嵌套 Seatbelt：`sandbox_apply: Operation not permitted`

现象：`xcodebuild` 或 `swift test` 报 `sandbox-exec: sandbox_apply: Operation not permitted`；
Swift 宏（如 `SwiftUIMacros.StateMacro`）报 `swift-plugin-server produced malformed response`。

原因：外层（工具/IDE 沙箱）已经给进程套了一层 Seatbelt，Xcode 的 SwiftPM 与 Swift 宏插件
服务器会**再套一层**，macOS 内核不允许嵌套沙箱。

对策：
- `xcodebuild` → 用 `tools/xcodebuild.sh` 包装，它注入
  `-IDEPackageSupportDisableManifestSandbox=1 -IDEPackageSupportDisablePluginExecutionSandbox=1`
- 直接调 `swift build/test` → 加 `--disable-sandbox`（禁用 SwiftPM 自己的沙箱）**并且**
  `-Xswiftc -Xfrontend -Xswiftc -disable-sandbox`（禁用编译器给宏插件套的沙箱，两个都要）

```bash
cd app/TypetodoCore
swift test --disable-sandbox -Xswiftc -Xfrontend -Xswiftc -disable-sandbox
# 基线：293 用例 / 0 失败 / 约 13 秒
```

### 2. Sparkle 首次解析极慢（10 分钟 0 字节）

对策：`app/scripts/fetch-sparkle.sh` 直接把 tarball 下到 `app/vendor/Sparkle`，
工程改成 `XCLocalSwiftPackageReference`，`Package.resolved` 删除。解析从分钟级降到秒级。
`app/vendor/` 不入库，新克隆先跑一次该脚本。

### 3. 签名：证书叫 Apple Development，不叫 Mac Development

`xcodebuild` 默认给 macOS app target 找 `Mac Development`，本机只有 `Apple Development`（team `PUW227GYGV`）。
命令行构建用临时 ad-hoc：

```bash
CODE_SIGN_IDENTITY="-" CODE_SIGN_STYLE=Manual CODE_SIGNING_REQUIRED=YES
```

### 4. `EXECUTABLE_NAME` 残留导致 codesign 失败

现象：`code object is not signed at all. In subcomponent: .../MacOS/Typefree`。
原因：改了 `PRODUCT_NAME` 但 target 里 `EXECUTABLE_NAME` 还是旧名，签名时找不到可执行文件。
改名类操作要一口气检查四处：`PRODUCT_NAME` / `EXECUTABLE_NAME` /
`INFOPLIST_KEY_CFBundleDisplayName` / `Info.plist` 的 `CFBundleExecutable`。

### 5. 版本号双份且不一致

`Info.plist` 里写死 `0.1.0` / `1`，但工程里 `MARKETING_VERSION = 2.0`、
`CURRENT_PROJECT_VERSION = 2.0.0`（上游试用期遗留）。因为 `GENERATE_INFOPLIST_FILE = NO`
且 Info.plist 没用 `$(MARKETING_VERSION)`，工程里那份**不生效但会误导**。已对齐为 0.1.0 / 1。

### 6. 麦克风 entitlement 只在发布脚本里

上游 `CODE_SIGN_ENTITLEMENTS` 没写进工程，只有 `build.sh` 在 Developer ID 重签时才带
`Resources/*.entitlements`。结果 Xcode/命令行构建出的包里只有 `get-task-allow`，没有
`com.apple.security.device.audio-input`。已补进两个 target 级配置。

自查：

```bash
codesign -d --entitlements - --xml /tmp/TypetodoDerived/Build/Products/Debug/Typetodo.app \
  | plutil -p -
# 期望含 com.apple.security.device.audio-input => true
```
